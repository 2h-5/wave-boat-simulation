# Wave & Boat (Local Test)

This `branch` is used to **test** if I can still successfully push all the changes into GitHub after I **imported** my work as Unity package following the procedures after `build-initial`.

###### It looks like I can commit and push everything successfully since I created a separate `branch` to handle new updates, which turns out that it is a good practice to *bring changes to a new `branch`* before modifying anything in your project in case to prevent commiting errors for Unity projects. 

## P. S. 

###### This is a reminder for both me and other learners if there are still issues to face:

It is also a good practice to always include a **".gitignore"** file inside your repo to prevent irrelevant  or sensitive files from cluttering your repo.

There are tons of different things to add in **".gitignore"** based on different scenarios, but these things are mainly included for most of Unity projects:

```
/[Ll]ibrary/
/[Ll]ogs/
/[Uu]ser[Ss]ettings/
```
